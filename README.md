# Distributed Workflow Orchestration

> **Track:** OpenClaw Real-World Lab Build (Track 3)
> **Course 3 of 5**

Design and deploy task queues, workflow DAGs, and inter-node communication across the Mac Mini cluster.

---

## Modules

### Module 1: Task Queue Architecture

**Learning Objectives:**
- Deploy Redis on a dedicated node
- Configure Celery workers on each Mac Mini
- Monitor task queue depth and worker health

### Module 2: Workflow DAGs with Prefect/Airflow

**Learning Objectives:**
- Model lab workflows as directed acyclic graphs
- Schedule recurring jobs with cron triggers
- Handle task failure and retry logic

### Module 3: Inter-Node Communication Patterns

**Learning Objectives:**
- Implement pub/sub with Redis channels
- Use gRPC for low-latency RPC between nodes
- Design event-driven task handoffs

### Module 4: Load Balancing Across Mac Minis

**Learning Objectives:**
- Configure NGINX as a reverse proxy
- Implement round-robin and least-connections strategies
- Monitor per-node CPU and memory load

### Module 5: Monitoring & Alerting with Prometheus

**Learning Objectives:**
- Deploy Prometheus and Grafana on the cluster
- Define alert rules for node failures
- Build a cluster health dashboard
